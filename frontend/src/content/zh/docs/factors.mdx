# 八个基础因子

以下为正式研究模块的**目标公式，尚未实现**。当前策略实验室的原始值和标准化分为人工样例，仅从这些固定分数计算等权类别分、加权贡献和总分，不代表已完成历史行情计算、截面标准化或正式选股。基础概念可先在[知识学习室](/zh/workspace)阅读图解。

设 C、H、L 为同口径研究收盘价、最高价和最低价；V 为成交量，A 为成交额。`MA_n` 为截至当前日、包含当前日的 n 日简单平均。所有窗口按交易所日历对齐，必要输入无效则该因子无效。

| 类别 | 因子 | 首版公式 | 方向与解释 |
| --- | --- | --- | --- |
| 趋势 | 均线相对位置 | `MA20(C)_t / MA60(C)_t − 1` | 较高表示中短期趋势相对较强 |
| 趋势 | 均线变化率 | `MA20(C)_t / MA20(C)_(t−5) − 1` | 较高表示近期均线抬升 |
| 动量 | 5 日收益率 | `C_t / C_(t−5) − 1` | 较高表示近期动量较强 |
| 动量 | 20 日收益率 | `C_t / C_(t−20) − 1` | 较高表示中期动量较强 |
| 量价 | 成交量比值 | `V_t / mean(V_(t−20), …, V_(t−1))` | 相对前 20 日放量程度 |
| 量价 | 价量变化相关性 | `corr(r_d, g_d), d=t−19…t` | `r_d=C_d/C_(d−1)−1`；`g_d=V_d/V_(d−1)−1` |
| 流动性 | 平均成交额 | `mean(A_(t−19), …, A_t)` | 较高表示流动性相对较好 |
| 风险 | ATR14 比例 | `ATR14_t / C_t` | 较高表示波动风险较高，评分时反向 |

## ATR 计算

真实波幅 `TR_t = max(H_t−L_t, |H_t−C_(t−1)|, |L_t−C_(t−1)|)`。ATR14 首个值取连续 14 个有效 TR 的简单平均，后续采用 Wilder 平滑：

```
ATR14_t = (13 × ATR14_(t−1) + TR_t) / 14
```

## 无效值口径

- 价量相关性使用 20 组有效配对与 Pearson 相关系数；分母为零、窗口不足或某序列零方差时无效。
- 成交量比值分母不含当日；历史均量为零时无效。
- 成交量比值本身没有看涨方向；评分时使用派生特征 `sign(r_t) × log(1 + 成交量比值)`。

## 标准化与评分

当日截面缩尾（2.5%/97.5%）后计算 `z = (x − median) / (1.4826 × MAD)`，截断至 [−3, 3]，映射为 `s = 50 + (50/3) × z`；风险因子取 `100 − s`。类别内等权平均，再按风格权重求和。合格截面少于 20 只时暂停正式排名。
