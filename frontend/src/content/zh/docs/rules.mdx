# 交易与费用规则

## 当前合成演示

训练从十万元空仓开始，状态只在浏览器内存保存。每只证券有独立的合成日线，日期为固定工作日样例，不代表交易所日历。下单在下一样例日开盘加减 5bp 滑点，先将价格量化到分，再按成交额 0.03%（最低 5 元）计算佣金并按分记账；持仓按当天收盘估值。新买入股票当天不可卖，推进至下一样例日解锁；最后一天拒绝新委托，缺行情不能借用其他证券价格。

演示仅覆盖所列主板证券的普通买卖，未模拟印花税、过户费、停牌、涨跌停与公司行动，不是正式 A 股执行引擎。委托在下一样例日执行，可卖数量展示的是当前日状态；下一日执行的卖单需届时已解锁。刷新或重新进入页面会重置；没有后端持久化或服务端未来数据隔离。

策略实验室是独立的固定展示样例，没有调用训练执行模块，也没有真实回测。

## 正式后端的目标规则（待实现）

后续回测与 K 线训练将共用后端执行模块。以下为拟定教学参数，实际费率与证券交易规则需核对并冻结为执行规则版本。

| 参数 | 建议初值 | 说明 |
| --- | --- | --- |
| 初始资金 | 100,000 元 | 纯虚拟资金，不允许融资和做空 |
| 最大持仓数 | 10 只 | 排名不足或无法成交时保留现金 |
| 调仓频率 | 每周最后一个交易日收盘生成信号 | 下一交易日开盘尝试成交 |
| 目标仓位 | 每只目标为信号日净资产的 10% | 不足 10 只时不提高其他股票比例 |
| 佣金 | 成交额 0.03%，每笔最低 5 元 | 教学默认假设，可配置 |
| 滑点 | 买入 +5bp，卖出 −5bp | 相对下一日开盘价 |
| 订单有效期 | 仅下一交易日开盘一次尝试 | 未成交部分撤销 |

## 事件顺序

1. 信号日 t 收盘后计算指标、排序和目标委托，保存快照。
2. t+1 处理权益确认、实际到账、股份解锁与交易状态。
3. 使用 t+1 未复权开盘价及滑点先处理卖单，再处理买单。
4. 检查现金、持仓、可卖数量、申报数量、价格限制和费用；可成交则记账，否则记录拒单原因。
5. t+1 收盘按可获得价格估值，保存现金、持仓市值、应收权益、费用和净资产。

## T+1 与价格约束

- 当日新增股票不能当日卖出；按买入批次记录股数和买入日期。
- 主板买入按 100 股整数倍；其他板块采用独立规则表。
- 开盘涨停拒绝买入，开盘跌停拒绝卖出；停牌不成交。
- 日线回测无法还原订单队列与盘中路径，首版不实现限价单与盘中止盈止损。

## 训练模式

目标是让日期、图表、因子、候选与账户估值使用同一回放时间；后端仅返回截至回放日的行情与指标。服务端隔离、持久化及真实交易规则仍待实现，不能由当前前端演示推断这些能力已经具备。
