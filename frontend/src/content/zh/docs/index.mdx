# QuantFlow AI 帮助文档

从导航中四个模块旁的圆形 **?**，随时回到这里。首次使用可以先看[首页介绍](/zh)，再按 **学知识 → 看实验 → 练交易 → 做复盘** 的顺序体验。

<HelpSearch />

## 四个模块怎么用

| 模块 | 从这里开始 | 当前范围 |
| --- | --- | --- |
| [知识学习室](/zh/workspace) | 用图解认识 K 线、量价关系、ETF 和交易风险 | 入门课程与教学示意图 |
| [策略实验室](/zh/lab) | 搜索样例股票，查看候选评分，再了解回测结果如何阅读 | 搜索仅覆盖预置证券；评分与回测是相互独立的展示样例 |
| [K 线训练场](/zh/training) | 在合成行情中提交虚拟委托并推进日期 | 内存账户，刷新或离开后重置 |
| [实验记录](/zh/experiments) | 了解复盘时需要保留哪些参数、版本和结果 | 固定记录示例，尚未保存本次实验或训练 |

股票搜索位于策略实验室内，支持按证券代码或中文名称查找预置样例；这里的搜索用于查找站内帮助内容。ETF 课程用于知识教学，当前训练场不支持 ETF 交易。

## 规则与进一步阅读

- [八个基础因子](/zh/docs/factors)：8 个量价因子的首版公式、窗口与无效值口径。
- [交易与费用规则](/zh/docs/rules)：当前演示范围，以及未来后端共用执行模块的目标规则。

当前数据由本地程序合成或人工预设，**不是真实历史或实时行情**。训练刷新或重新进入页面会重置；没有账户持久化、真实回测、服务端未来行情隔离或访客账户服务。真实数据来源与使用条件、版本清单及公开部署仍待验证。
