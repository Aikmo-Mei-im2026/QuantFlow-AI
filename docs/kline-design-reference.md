## 采用的设计

宽屏采用账户信息、主图、回放与交易控制三栏；窄屏自动排列。主图展示价格刻度、日期、OHLC、成交量副图、MA5/10/20、十字线、B/S 成交标记。可以缩放和移动已回放的历史窗口。

训练先展示 20 根合成日线作为观察窗口，账户仍为十万元空仓。手动推进或自动播放只增加一个样例日；播放速度为 0.5×、1×、2×，1× 为每根约 1.5 秒。切换证券、修改委托或提交时暂停播放；切出页面暂停，末日停止。

快捷键空格推进，B/S 只切换方向，不直接下单；表单及按钮聚焦时不触发全局快捷键。重置按钮明确清空当前练习账户。

## 本项目保留的规则

- 用户在当前样例日提交，下一样例日开盘价加减 5bp 滑点后成交，避免用已知收盘信号按同一收盘价成交。
- 价格与佣金先量化到分，金额及现金统一按分记账；佣金 0.03%，最低 5 元。
- 新买入股票当日不可卖，下一日解锁；账户按当前日收盘估值。
- 交易引擎为临时演示纯函数，正式后端建立后由统一 execution 接管。

## 未复制为当前功能

没有新增 Flask/PyWebView、真实行情、AI 交易或点评、多用户持久化、动态复权。盲盒股票选择已于 2026-11-14 实现并于 2026-11-15 重构：训练场分「指定模式 / 盲盒模式」两种，共用同一张「数据源 / 起始日期 / 初始资金」表单——起始日期改为原生日期控件并按所选数据源顺延到下一条可用日线（不再是 19–40 共 22 项下拉），初始资金放开为任意元金额（不再限档案四档，档案值只作默认），数据源分为合成样例（6 只主板）、站点快照（需构建期 `NEXT_PUBLIC_TRAINING_SNAPSHOT=1`，默认关闭且尚未验收）、本地导入 JSON 三池；盲盒在所选数据源里随机抽取对该日期有行情覆盖且还能推进的股票，揭示前遮蔽代码与名称，揭示由「结束并揭示」或到达最后一根触发，纯函数见 `frontend/src/lib/demo-training.ts`；参考设计的多股票盲盒题库在本地导入路径上已可承载 1–5 只标的，站点侧统一题库仍未实现。MACD/KDJ/RSI/BOLL 已于 2026-11-14 在 K 线训练营实现（主图 K线/收盘线切换、日线/周线周期（周线为 11-15 新增，指标按当前周期重算）、成交量、BOLL(20,2) 叠加、副图 MACD(12,26,9)/KDJ(9,3,3)/RSI(14)，滚轮缩放与左右拖动看历史），但由 `frontend/src/lib/demo-indicators.ts` 在浏览器端对合成样例即时计算，参数与口径见 [验收记录](frontend-demo-verification.md)。当前是主板合成样例，仅计佣金，不覆盖正式税费、停牌、涨跌停和公司行动。图表只显示截至回放日的数据，但全部合成行情仍在浏览器中，不宣称实现服务端未来数据隔离；盲盒的遮蔽只作用于页面文本，客户端内存与开发者工具仍可见真实代码，不构成防作弊。

真实数据与使用许可、后端以及 Qoder Sites 部署仍按 S03/S04/S10 之后的任务推进；参考项目的功能不能视为本项目已有能力。
